- 🧑‍🎓 **Students** enrolled in the Prime Batch who want a reference hub

- 💼 **Placement aspirants** who need structured AI/ML preparation
- 📖 **Anyone** who wants clean, organized AI/ML notes and code

## 🚀 How to Use This Repository

```bash
# Step 1: Clone the repository
git clone https://github.com/ravixpanchal/prime-batch-apna-college.git

# Step 2: Move into the folder
cd AI-ML-Prime-Batch

# Step 3: Install required packages
pip install -r requirements.txt
```

```python
# Step 4: Navigate to any topic and run
# Example — running the SVM notebook:
cd Machine_Learning/SVM
jupyter notebook SVM_Complete.ipynb
```

> 💡 **Recommended:** Use [Google Colab](https://colab.research.google.com/) or [VS Code](https://code.visualstudio.com/) with the Jupyter extension for the best experience.
